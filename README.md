# 🤖 Clube do Foco - Galeria Interativa de Trabalhos com IA

Uma galeria interativa de trabalhos realizados com ajuda de Inteligência Artificial, incluindo sistema de busca, filtros por categoria e documentação completa.

## ✨ Funcionalidades

- 🔍 **Busca em tempo real** - Encontre trabalhos rapidamente digitando palavras-chave
- 🏷️ **Filtros por categoria** - Text, Imagem, Código, Design e Dados
- 📱 **Design responsivo** - Funciona perfeitamente em todos os dispositivos
- 🎨 **Interface moderna** - Design dark com animações suaves
- 📊 **15 projetos documentados** - Exemplos reais de uso de IA

## 🚀 Como Usar

### Acesso Rápido
Abra o arquivo `index.html` no seu navegador.

### Servidor Local
```bash
# Clone o repositório
git clone https://github.com/Silviosb88/clubedofoco_v2-genspark.git
cd clubedofoco_v2-genspark

# Abra com um servidor local (exemplo usando Python)
python -m http.server 8000
# Acesse: http://localhost:8000
```
